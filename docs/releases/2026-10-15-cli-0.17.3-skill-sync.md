# CLI 0.17.3：Skill 目录同步机制验收

2026-10-15（Asia/Shanghai）。本次范围为 dev 合入与 CLI/npm 发布；未部署网站或独立 Makaron 插件。公开静态 discovery 的源文件已更新，生产网站副本随后续网站部署更新。

## 改动

之前，主要入口目录在多份文档手动维护，内部 Skill 更新不会让旧路由证据失效，也没有统一 tarball/registry/fresh-install 验收命令。

现在，`config/makaron-external-skills.json` 维护精选名单及中英文需求摘要，内部 frontmatter 提供描述、触发词和输入要求；`build:skill-sync` 自动生成入口表、机器目录和 public 副本。正文流程仍由内部 Skill 负责。9 个主要入口与四项排除保持不变。

相关更新由 CI 检查生成文件是否过期、路由回执是否对应当前源文件，以及包内容变化是否升版；普通 CI 不调用模型。`release:cli:prepare` 检查并输出实际 tarball，`release:cli:verify` 验证 npm 与全新安装。项目 AGENTS.md 和 release checklist 已接入这套流程。完整说明见 [同步机制](../agent-guidance/makaron-skill-sync.md)，入口见 [简短中文文档](../agent-guidance/makaron-cli-entry.zh.md)。
