## What changed in 1.2 (official, released 2026-11-05)

Sources: [Gemini API Omni docs](https://aistudio.google.com/docs/omni),
[pricing](https://aistudio.google.com/docs/pricing#gemini-omni-1.2-flash),
[launch post](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/).

| | 1.1 Flash | 1.2 Flash |
| --- | --- | --- |
| Model id | `gemini-omni-1.1-flash` | `gemini-omni-1.2-flash` |
| Output length | 3-10s | 3-15s, typed `response_format.duration` ("3s".."15s") |
| Source video for edit | <=10s (Makaron 10.5s) | <=15s |
| Extend | +3-10s, total 40s | +3-10s, total 30s |
| Follow-up edits | `previous_interaction_id` | same, promoted as multi-turn conversational editing |
| References | 6 images | 6 images (<=3 per character, 2 characters), motion clips <=3s |
| Speech | native audio | multi-speaker dialogue, clearer lip-sync |
| Prompt roles | `<IMAGE_REF_n>` control tokens | control tokens deprecated, natural language roles |
| Video output price | $17.50 / 1M tokens | $12.00 / 1M tokens (~30% cheaper) |

Tokens per second are unchanged (360p 1,931; 720p 5,792; 1080p 8,688; 4K 17,376),
so 720p goes from $0.101/s to $0.0695/s. `gemini-omni-1.1-flash` auto-routes to
1.2 on 2026-12-03. Languages other than English are untested by Google.

## Product changes

- `google-omni` keeps its id and now calls `gemini-omni-1.2-flash`
  (`src/lib/google-omni-video.ts`, capability in `video-model-capabilities.ts`).
- Generation 3-15s; extension still 3-10s per call (validated) and 30s cumulative.
- Duration is sent as `response_format.duration` instead of a prompt sentence.
  Edits omit it and keep the source length.
- Media roles are written in natural language ("Image 1", "the source video").
  `<<<media_N>>>` markers map to image ordinals even when a timeline video
  occupies an earlier slot (previously misaligned).
- Conversational editing: `video_operation: "edit"` on an Omni-generated
  snapshot (<=15s) continues its Google interaction via `previous_interaction_id`
  without re-uploading. Uploaded sources still use the inline upload path.
- Retake selections up to 15s. Pricing migration
  `20261107210000_google_omni_12_pricing.sql` updates only rows still on the 1.1
  seed rate. **Not applied to the shared database yet**; until it is, 1.2 is billed
  at the old 1.1 rate (observed: 12s 720p = 244 credits; 1.2 rate = 167).
- Prompts (layered + legacy), MCP/CLI docs, locales, public skill and
  core-prompt amendments synced. CLI version not bumped yet.

## Experiments (direct API, same request per model, run in parallel)

Reproduce with `scripts/benchmark-google-omni-1-2.mjs`. Media lives in the ignored
`artifacts/google-omni-1-2/`; reviewer cuts are in its `review/` folder.
Reference: Pixel Wizard + Spark crop of `public/brand/makaron-spark-pixel-wizard-concepts.png`.

| Run | Model | Wall time | Output | Notes |
| --- | --- | ---: | --- | --- |
| E1 10s 720p, 2-line dialogue | 1.1 | 56.6s | 1280x720, 10.03s, AAC | Wizard eyes drift to cartoon style; Spark becomes a plain star |
| E1 same request | 1.2 | 55.4s | 1280x720, 10.03s, AAC | Wizard keeps pixel eyes/face; Spark also a star |
| E2 15s 3 beats, 2 speakers | 1.2 | 97.7s | 1280x720, 15.04s | Beats on time (frame 0-5s, sunset fill ~5s, high-five ~12.5s); one extra mini star |
| E3 follow-up edit "Spark gold" | 1.1 | 77.7s | 10.03s, SSIM 0.953 vs source | **Burned in a subtitle "And I'm Spark!"** |
| E3 same follow-up edit | 1.2 | 93.1s | 10.03s, SSIM 0.965 vs source | Only Spark recolored; clean |
| E4 1.2 extends a 1.1 interaction (+5s) | 1.2 | 101.5s | 15.04s, prefix SSIM 0.991 | Cross-version lineage works, old snapshots stay extendable |

Both models accepted the typed `duration` field. Both bill the previous clip as
input video tokens on a follow-up edit (57,920 tokens for 10s 720p, ~$0.087).
Gemini 3.8 Flash blind judge (E1): dialogue transcribed correctly for both;
fidelity Wizard 7/7, Spark 5 vs 6; lip-sync 6 vs 4 (1.2 pixel mouth moves little).
Treat the judge as a weak signal; it also claimed subtitles in E1 1.1 that the
contact sheet does not show.

### Prompt language A/B (same content, 12s 360p, 1.2, two runs each)

| Prompt | Unrequested human wizard | Wall time |
| --- | --- | ---: |
| Chinese (the Agent's exact prompt) | 1 of 2 (plus the E2E run: 2 of 3) | 70.5s / 73.0s |
| English translation | 0 of 2 | 60.2s / 61.3s |

English runs also kept Spark's radiating-ray design more often. Small sample, but
consistent with Google's note that only English is validated. Fix: `animate.md`
(Omni bullet) and the always-loaded `generate_animation` `model` parameter now say
to write the whole Omni prompt in English and keep only quoted spoken lines in the
language to be heard.

Re-run on a fresh project (`eecca3fc-af63-4ce9-892a-b2f0615d6f85`): the Agent wrote
an English prompt with timed beats; the 12s result had no extra characters (143s).
The follow-up edit "Spark gold" first failed with Google `403 A valid API key or GCP
project is required` (refunded, 0 credits); the same interaction succeeded
directly 30s later, so it was transient. The retried Agent edit used the lineage
path, returned 12.03s, **SSIM 0.971** vs the source, only Spark and its sparkles
recolored. Note the old project's conversation kept the pre-fix guide in history,
so guidance changes only show on a fresh conversation or a re-read.
