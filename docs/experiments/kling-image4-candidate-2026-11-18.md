## 一手接口与价格

本轮重新核对 [fal 文生图 API](https://fal.ai/models/kling/v4/text-to-image/api)、[参考图 API](https://fal.ai/models/kling/v4/image-to-image/api)、[长图 API](https://fal.ai/models/kling/v4/long-image/api)，以及 [可灵原生价格页](https://kling.ai/dev/pricing?scrollTo=image)、[4.0 API](https://kling.ai/document-api/api/image/4-0/image-generation) 和 [认证文档](https://kling.ai/document-api/api/get-started/authentication)。fal 模型元数据标注 commercial。本地保留 schema 和报价快照。

普通图支持 2K/4K/8K、指定比例、1–9 张独立图、2–10 张系列输出；参考输入合计最多 10 张/元素，元素最多 7 个。输入为 PNG/JPEG/WebP，≤30 MiB、边长至少 300px、比例 0.4–2.5。精确 schema 没有 alpha/background/mask 参数。单张模型接入拒绝不支持的透明/格式/尺寸请求，不通过换模型满足。

可灵新 Image 4.0 接口采用新 API Key。现有本地/生产配置只有旧 AK/SK，没有这条接口要求的新 Key；官方文档明确旧认证对应旧版 model_name 接口。因此本轮**原生侧只核对文档与报价，没有原生通道生成**，没有新注册、购买套餐或充值。

## 实图结果与比较边界

**同规格文字海报**：三家使用完全相同的英文 prompt、1:1、2K、opaque PNG、无参考输入。Kling 海报留白规整，中英文标题、日期、上海地点及底部文字可读，金属腿与白桌按要求出现；Seedream 使用更具空间感的两把椅子构图；GPT 的字体醒目、材质浓厚，但椅子变为整体软包腿，没有满足 brushed metal leg 细节。这是单张 prompt 遵循观察，不是所有场景质量排名。

| 新 2K 海报 | 供应商阶段 | 媒体供应商费用 | 产品 credits |
| --- | ---: | ---: | ---: |
| Kling 4.0 / fal（探针） | 45.58s | $0.063 | 不经过产品扣费 |
| Kling 4.0 / fal（chat 验收） | 57.19s；整 run 74s | $0.063 | 图片13 + Agent1 |
| Seedream 5.5 / EvoLink（CLI） | 34.31s | 标价 $0.028 | 6 |
| GPT Image 2.6 / OpenAI direct（CLI） | 13.65s | 用量记录 $0.05065 | 11 |

GPT 使用 quality=low、reasoning/complexity=high；Seedream 使用 standard。这两个基准通过当前候选的 CLI/MCP 路径调用，未选择恢复模型。耗时含各适配器的提交/轮询/下载范围差异，不是同时并发压测，也不是用户点击到显示。供应商资金账单未独立对账。

**品牌完整画面**：使用 Skill 的真实品牌 reference sheet。Kling 保留紫色像素脸、软体鬼魂、紫帽和从卡片流出的粉青 Spark；角色和帽子完整入画，但角色明显偏大、产品卡细节较简化，未完全满足 sidekick 约20%画面占比。旧 GPT/Seedream 样本可帮助观察品牌表达，不能直接当成同规格胜负：它们是 11月13日的 1K，Kling 是 2K，prompt 中尺寸词同步改为2048。旧样本没有重新收费或生成。

**透明探针失败**：直接请求透明素材，Kling 返回 RGBA PNG，但全部像素 alpha=255，棋盘格被直接画入背景。没有后处理去背景，也没有把它计作透明成功。历史 GPT/Seedream 图具有真实 alpha，但来自此前独立测试。产品层不宣称 Kling 原生透明支持。

**固定原图局部编辑**：三家使用同一固定源图，SHA-256 `bbd9051dad42a91ab512b9b1ade7b2582e69545331fa02a0cbe6415fe44bb9fa`。Kling 把帽子改为橙色，主体、卡片和光带的大结构仍在；输出由源图1K变为2K，不能声称未编辑区逐像素不变，也不能把历史同尺寸误差指标直接套用到它。没有原生 mask 控制。

**2K/4K/8K取舍**：原始文件分别为2048²、4096²、8192²，约4.55/18.50/66.53 MiB；供应商探针约45.58/69.92/125.63秒。三个档位是分别采样，布局和材质会变化，不是同一张图的无损放大。高分辨率适合需要原始像素的交付，但增加文件体积、传输和内存成本，本轮不能证明8K在所有细节上胜出。8K再经CLI实测为8192²、67,028,220字节，原始字节完整保存。

**长图**：网页图能产生连续的导航、hero、商品区、材料故事和页尾视觉，可作为视觉稿；文案、按钮、hover说明全部是栅格内容，不能点击，也不能作为可编辑网页。电商 long 2K 实测2048×53829，约1.10亿像素、377秒；short 2K也达到2048×20289，说明“长度档”并不是固定像素高度。应单独做异步交付、尺寸/内存和长图浏览体验设计后再开放，不能把普通单图后端当成长图接口。

旧 Pokémon 拒绝记录保留在 [Seedream 对照报告](seedream55-candidate-2026-11-13.md) 与对应原始证据中。本轮没有重跑已拒绝项、改 prompt 规避、换角色或隐藏 fallback，也没有虚构新的 Kling 拒绝结果。

## 产品验收与故障证据

- `makaron chat → generate_image → fal → 快照保存 → 独立读取项目媒体/快照 → 原图下载` 实测成功。保存的精确 prompt 与冻结值逐字一致，模型是 `kling-image-4.0`、provider是`fal`、providerModel是`kling/v4/text-to-image`、2K、PNG；message_id存在，重读快照ID及原图SHA一致。
- Chrome 实际看到项目生成结果与模型标注，随后项目私有化；本地 Chrome没有登录，因此未完成“已登录私有项目GUI重开”验收。当前能确认的是认证API重读与原图下载。内置浏览器本会话不可用，使用Chrome展示并实际查看对比页。
- CLI/MCP 8K：单次生成、保存后返回resource link，CLI下载得到8192²原图，与fal原始字节SHA一致。模型与provider均明确，没有base64大响应替代原图。
- 同一UUID再次调用：返回已有COMPLETED回执与同task ID，没有二次生成。共享usage账本只有本轮chat图片13 credits与CLI图片32 credits两行。
- 一次测试脚本传入非UUID request ID被schema拒绝，未进入付费提交；修正为UUID后才进行一次生成。该输入错误与完成请求的重放错误均保留，不当成图片生成失败样本。
- 17个直接fal请求全部完成，共19张图；另4个真实产品媒体请求全部完成，共4张图；合计21次付费媒体提交、23张新图。透明需求语义失败1项，与HTTP/出图成功分开统计。没有结果不明的遗留付费任务。

107项相关测试通过；最后MCP描述补齐后重跑45项通过。TypeScript、CLI smoke/upload、四语i18n、Skill build/sync均通过。受控路由预检4/4、实际媒体操作0。改动文件ESLint无错误，保留上游`agent-tools.ts`未使用locale警告。故障测试覆盖价格变化、不可读输入、缺回执、付费POST结果不明、拒绝、持久化失败、并发同ID及重复请求；没有用真实破坏生产账本的方式制造退款。
