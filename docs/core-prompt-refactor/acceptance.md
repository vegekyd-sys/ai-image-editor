- 旧版：`3193cd36`，独立 baseline runner，localhost:4353。
- 初始结构候选：`90dd149d`，独立 candidate runner，localhost:4352。
- 补强候选：本次变更中的 `agent.md` 多图指南规则和 `video-workflow.md` H3 首帧画幅规则。离线首动作复测及实际 localhost:4354 图生视频使用此版本；其余第一轮媒体没有混算成此版本已通过。

- 仅原始捕获→媒体执行的样本不走项目保存，和完整 CLI 工作流分别记录。

图片观察：局部改色保留了领结黑色条纹，但人像海报袖口、恢复、中文叠字和抠图均有未请求区域变化。透明抠图六张有真实alpha且1440方形画布一致，仍不能据此判主体像素保真。Wild候选一张增加英文文字，捕获的 editPrompt 明确禁止文字，属于真实输出失败，不能伪装成缺少禁词。不同模型的公共缺陷与重构引起的退化尚未完全分离。

修复窗口外SSIM（0–2秒 / 3–5秒）：旧版0.988199 / 0.941906，候选0.985746 / 0.731561；音轨解码PCM均不完全相同。视频fps被变为25，不能把低SSIM直接全部归因画面重绘；但“窗口外原画面原声不变”的严格门槛没有通过。容器时长不可代替视频流时长。

长视频旧版一次OpenAI参考图生成回退Gemini，该步骤不计同模型胜负。局部修复走现有Grok订阅通道，整片源编辑走API；两类分开比较。补发继续指令不是首次自主完成。

p90与cache分类见JSON。两版各39/40次有缓存读取；只有问候各一次无cache read，不能宣称是充分冷启动测试。部分其他QA与本地构建重叠，这组是实际观测而非严格隔离的因果基准。改写略慢、增强首字p90更慢，故“所有普通场景更快”未验收。

最终Core 7,455字符，相对11,875减少37.2%；静态system+tools 79,576，相对102,578减少22.4%。这是字符而非实际token下降百分比。

## 验证与复现

- 最新原文归属/创作哈希/bundle检查通过：54段旧Core、12份关键创作正文、2套组合指南。
- `corePromptLayers`、`agentPromptPolicy`、`videoReplicationPrompt`：3文件26测试通过。
- `npm run lint`、`npx tsc --noEmit`、`npm run build -- --webpack`通过。默认Turbopack build在本worktree的外部node_modules软链接处失败，因此切换Webpack构建验证；不是把该失败记作产品测试通过。
- 前一阶段完整单元测试1658通过、1跳过是旧阶段证据，不冒充本次最新完整回归。
- 所有媒体使用ffprobe和完整ffmpeg解码；音轨存在、ASR、黑帧检测各自独立。手机报告评分状态刷新保留已通过真实浏览器交互。

脚本位于 `benchmarks/core-prompt/`：

1. `acceptance-cases/*.json` 为持久化请求/判定；先准备QA素材到 `artifacts/core-prompt/acceptance/inputs/`。源视频案例的占位URL必须替换为上传所得URL，不能直接发给供应商。
2. `evaluate.ts --live --cases <case-file> --repeats 3 --output <captures>` 只捕获首动作。
3. `accept-media.ts --live --kind image|video --captures <captures> --output <outputs> --expected <n>` 执行实际媒体调用。日志在付费提交前保存，已知taskId恢复轮询，未知提交结果不自动重复。
4. `accept-workflows.mjs --live --case <case> --repeats 3` 跑CLI→Agent→工具→项目。可用 `--stage` 与 `--candidate-url` 分离修复后候选，禁止混用旧输出充数。
5. `collect-acceptance.mjs` 下载、探测并解码；`export-acceptance.mjs --live` 通过真实composition export导出。无设计类型的初次脚本错误在修正识别为composition后重试，未产生重复付费导出。
6. `accept-audio.ts` 对原生对白执行现有ASR；`build-acceptance-report.py <site-dir>` 仅复制选定本地媒体与清理后的元数据，使用内容哈希文件名，保留随机A/B及本地评分。

报告仍发布到此前同一个仅本人可见的Sites站点。原始日志、凭据、签名URL、QA项目标识不进入报告。评分未上传服务端，需用户复制或下载后交回；不能声称已获得用户盲评。
