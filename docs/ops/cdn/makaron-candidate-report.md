# Makaron 按需缓存与并发下载候选验证

2026-10-20。范围为全站公开图片、视频的通用访问规则；十条视频仅为验收样本，不是路径白名单。不提前迁移历史媒体，不修改源文件。此候选尚未切入生产。

## 结论

实现和候选云端验证已完成。重复访问减少源站正文流量；在当前浏览器网络上，没有测出足以支持全站发布的速度提升。建议保留候选，暂缓全站上线；优先取得实际慢速用户网络样本以及一天内重复访问比例，再决定推广范围。

## 实测速度

| 客户端与文件 | 原站单路 | 候选冷态 | 候选热态单路 | 候选四路 |
| --- | ---: | ---: | ---: | ---: |
| curl，142 MB | 64.24 s | 66.19 s | 67.85 s（R2） | 17.58 s |
| curl，19.7 MB | 10.11 s | 10.09 s | 9.83 s（边缘） | 3.20 s |
| 内置浏览器，142 MB | 19.22 s | 未在本组测量 | 18.90 s | 18.66 s |

每组完整文件和分段重组 SHA-256 都一致。curl 四路是四个大 Range；浏览器使用编辑器同一模块、四路并发的 4 MiB 分块（共 35 个请求），不可把两者当作同一种用户路径。没有大陆三网验收；已观测 Cloudflare 节点为 NRT。

原图 433,683 字节：原站 1.17 s、冷态 1.25 s、R2 1.47 s、边缘 1.25 s。缩略图 97,559 字节：原站 1.13 s、冷态 0.99 s、R2 0.89 s、边缘 0.86 s。单次小文件差异不足以承诺稳定提速。

## 回源流量

两个受控视频样本合计 161,775,116 字节，各完成冷态、热态、四路重组三次读取：普通未缓存方式共需 485,325,348 字节正文；候选记录四次完整 origin GET，共 323,550,232 字节，减少 33.3%。热态没有 origin GET，仍有 HEAD 版本检查（这组共 13 次）。R2 读取文件和客户端校验均验证副本完整。

首次访问需要客户端与缓存填充各读取一份，最多 2 倍源正文流量。成功填充后，第二次完整读取累计打平，第三次累计节省 33%，十次约节省 80%；这些结论假设同版本、有效保留期内无重复失败填充。若大量资源一天只访问一次，总流量可能增加。当前候选副本一天过期，下一周期可能再次建立副本。以上不是 Supabase 账单节省比例。

## 实现与验证

- Makaron 已接入四路下载，保留付费检查、原生相册和第三方代理逻辑；40 项相关测试通过，TypeScript 通过。完整编辑器 UI 与真实 iPhone 保存尚未手工验收。
- 独立 Worker 使用匿名公开源地址；私有、签名、带身份请求不写共享缓存。R2 按 URL、Accept、ETag、大小分版本，源覆盖/删除经重新验证后生效。
- 最终候选版本 `b9b110ab-73fe-4fde-8a2b-13827b931bff`：十条 MP4、原图和缩略图均完整校验通过；Worker 14 项测试通过。缓存经历 MISS → R2 → 边缘 HIT。
- 首版 JavaScript 分流在大文件上触发 CPU 限制，产生截断响应；已改为原生流，并保留失败记录。失败响应不计入速度收益。R2 条件写入的 90 秒租约抑制跨实例重复填充。
- 小 Range 也可能触发整份缓存填充；后台寿命限制可能使大文件填充失败。5 GiB 以上绕过候选，500 MiB 以上不进入边缘 Cache API。Cache API 不是 Tiered Cache。
- R2 bucket 私有，已启用 `v1/` 一天过期。尚未修改生产域名路由、DNS 或原缓存绕过规则，也没有批量复制历史文件。
