元素即 clip

轨道顺序 = 画面层级。画布选中 ↔ 时间线选中双向联动；属性条字段来自 clip 类型或 Agent 组件的 propsSchema，覆盖旧 editable 的全部能力。

Agent 实时剪辑

每个 timeline_tx 由 Choreographer 逐 op 播放：Spark 光标移动 → clip 生长 / 让位 / 收缩 → 镜头跟随。状态立即生效，动画只是展示层。

生成中占位

Agent 先放 pending clip（进度环），生成完成由系统 tx resolve_pending 原地揭开，编排不必等生成。

协作不覆盖

Agent 运行时用户可继续编辑；按元素变基，冲突才让 Agent 重读。Agent 每一步是 undo 栈里的一步，也能在对话卡片里单独撤销。
