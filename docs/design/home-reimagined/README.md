## 设计

产品介绍与真实模板展示同等重要。首页是一片可进入的创作画布：大标题与五幅动态作品环绕，接洋红色大字，再进入错落的模板展览。保留现有登录、账号、Human / Agent、模板详情、上传和创作流程。

- 底色：`#000000`；文字：`#ffffff`；品牌：`#d946ef`；悬停：`#e879f9`；辅助文字：`#a1a1aa`；媒体底色：`#141414`。
- 字体：现有 Geist，中文使用系统中文字体回退；标题 34–74px，正文 14–20px。品牌继续使用现有 Makaron Spark 和字标。
- 首屏：中间文案保持开放空间；五个异形比例媒体框缓慢漂浮，滚动时轻微移动。媒体不加全屏着色。
- 模板：桌面四列，手机两列；交错高度、独立媒体边框、可操作分类；每次八个，显式加载更多，保留抵达产品介绍区的路径。
- 暂停保留视频当前帧；离屏或详情覆盖后释放后台媒体。系统减少动态效果偏好默认关闭自动播放与漂浮。
- 四种语言同时实现：简体中文、繁体中文、英文、日文。

## 第三轮：品牌统一与创作变形台

按用户的四项反馈完成：网页版互换水母王座与时尚造型 MV 的展示位置，比例依据实际视频元数据分别设为 13:24 与 7:4；手机保留原先拼贴顺序。首页四语文案统一使用 Makaron 品牌名。移除模板卡右上角播放/箭头图标。用一个可切换的功能展示区替换底部两段重复宣传和 CTA；页脚只保留品牌与隐私入口，顶部“产品”链接跳到新功能区。

### 功能展示

- 图片：拖动或键盘调整原片与作品的对比面积。原片和输出来自现有云屋幻梦模板；输出是该模板视频 4.5 秒处的真实帧，界面标为“作品定格”。
- 视频：播放现有时尚造型 MV，并完整容纳横屏内容；切走或离屏后暂停/释放媒体。
- 设计：以同一作品构成海报版式，支持洋红、冰蓝、暖白三种现场换色。
- 音乐：原创 Makaron 黑胶插画、动态唱片与波形，提供白日梦/夜航/出发三种情绪。这是创作方向的视觉介绍，没有假装提供音频试听。
- “用这个想法开始”将当前形态、所选配色或情绪回填到首屏对话框，聚焦并滚回创作入口；不会自动提交生成任务。
