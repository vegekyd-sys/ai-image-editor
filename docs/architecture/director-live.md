# Makaron Director 与通话画布

设计草案。Director 由 Makaron 提供。一个人只装 CLI，用自己的 Makaron 凭据，也应能开播、打开播放器、持续改戏、结束并取回录像。V Voice 是第一个嵌入端。

## 用户会看到什么

在讲解页点着一张图片，说「就用这张开场」。同一页的素材位置开始播放，旁边的图片、讲解和通话控制仍可用。直播期间一句新的场景描述就是创作输入。问「这是什么动物」交给 V 回答，说「给它戴一顶帽子」交给 Director，说「不对，换成蓝色」修正上一条。说「收播吧，回到刚才那张图」结束同一场直播，电话和讲解继续。结束通话也释放直播资源。

## 两个入口，一场直播

拟议 CLI 合同如下。以下为接口约定，具体可用命令以发布版帮助为准。

```sh
makaron director start --image opening.jpg --prompt "玩具火车驶入站台" --open --json
makaron director direct <session> "一只白鸽落在车头上"
makaron director status <session> --json
makaron director stop <session>
makaron director export <session> --output show.mp4
```

- CLI 可单独打开带画面的播放器。录制从播放端接收的媒体流取得。导出成功的凭据是文件已写入、含可解码的视频轨且有实际时长。显示容器和扩展名须相符。
- V 使用同一套 start、输入、状态和 stop 操作。会话标识与通话绑定，只能由该通话使用。播放器作为讲解素材嵌入；字幕、说话人、麦克风和通话始终由 V 管理。画布换页不会另开付费会话。
- 服务端用现有 Makaron 鉴权解析账户和 API key。开播、续租和控制须核验账户、开播凭据和会话归属。播放端只持有本场短期、限用途的连接权限。供应商密钥只在 Makaron 后端。密钥停用、浏览器关闭、CLI 退出、挂断和超时需要各自的释放路径。
- 开播请求有幂等标识。网络中断后按同一请求查询，避免重复付费。stop 可以重复调用。把「已发送」「生成侧已采用」「实际开始播放」「已停止」分别反馈给宿主。没有可关联到播放帧的版本信息时，V 只能说导演已收到调整。

## 迁移 Makaron TV 的工作，而非仅接模型

迁移基线是 Makaron TV 的原生 Director 路径，源码基线 `e29b9e9`。另一个逐段渲染的 Turbo 路径拥有独立的分镜规划，不应混入原生流的默认行为。

| 现有实现 | 迁移行为 |
| --- | --- |
| `director/semantic.js` | 每段转写保留 ID 与修订号。final 后并行做语义整理和 650 ms 自我纠正窗口。新发言使旧整理作废；已提交内容去重。 |
| `lib/voice-organizer.mjs` | 模型判断 send、wait、discard，保留主体、否定、动作顺序和自我纠正。最近三条已发指令仅用于消歧。失败保留草稿。 |
| `director/app.js` 和 `public/director-state.js` | 支持首图、开场、画幅、分辨率、seed 和记忆长度。连接中暂存指令；递增版本、合并尚未采用的改动、replan、停止、留帧、录制。 |
| `lib/director-proxy.mjs` | 限定信令目的地，由服务端提供 fal 凭据。媒体仍走浏览器 WebRTC，实时视频字节无需经过 CLI 标准输出。 |

V 适配已有的用户转写，在直播状态下把创作输入交给同一整理器。补半句、改口、纯口头语、普通聊天和结束直播走不同分支。单独运行的 CLI 可从文字或独立播放器的语音输入驱动同一场会话。V 接入时复用现有麦克风和 ASR，只消费用户轮次。

## 账户与运行时

会话需要记录所属账户、创建 key、开播幂等标识、上游会话归属、版本、开始/停止时间、到期时间及计费状态。密钥明文、SDP 和媒体地址不进入操作日志。启动失败、关页断线、长时间无心跳、重复 stop 和导出失败应能独立回查。

费用按实时会话计量。fal 公共页面标明每场至少计 60 秒；在产品计费里应与固定秒数的短片分开登记，按现有 Makaron 价格表做余额校验、预留、实际用量对账和失败释放。测试使用隔离的账户与价格数据。见 [供应商模型页](https://fal.ai/models/minimax/h3-max/director) 与 [Makaron 模型流程](../model-release-workflow.md)。

## 两条验收录像

1. 全新 CLI 安装，使用 Makaron key，选择已知首图开播，打开独立播放器，语音和文字各改一次，查看状态，收播，导出并实际播放。保留首帧、改动前后帧、可解码录像、会话归属与用量回执。
2. V 电话从讲解图片开播；在原画布上自然描述新角色，不追加「改进直播」；分两句纠正角色和背景；穿插一个知识问题；口头结束直播，继续讲解同一张图片。检验同一场会话的工具事件和实播画面。重复结束、挂断以及撤销 key 后不得继续开新场。

## 已验证的语义部分

PR 中的 `src/lib/director/` 提取了 TV 的语义缓冲、原生提示版本和整理器；通话宿主新增 chat 和 end 两种结果。独立 Director 的整理仍使用原来的三种结果。测试入口为 `node --test __tests__/director/semantic.test.mjs`。覆盖未说完、改口使旧结果作废、聊天不进入提示历史，以及生成回执和播放事实的区别。以开发环境 DeepSeek V4 Flash 单独跑过六条合成语音转写，得到两次场景指令、一次知识问题、一次等待、一次口头语和一次收播。这个结果只验证意图层。
