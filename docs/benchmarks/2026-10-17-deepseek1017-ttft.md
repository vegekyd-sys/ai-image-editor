## 用户指定通过 Makaron Chat CLI 续测

用户随后明确可以通过 `makaron cli chat` 完成验证。因此本批不依赖网页登录；不把 CLI 的结果算成页面 ID 绑定/事件 drain 的浏览器验收。

本批始终使用同一个候选 CLI 0.17.4，未改变代码、模型档位或请求内容。旧 Preview 为 `a1c40e84`，新 Preview 为 `68751ee0`。固定两个场景，每个六组 B/A 交错，共 24 次 Chat：

- 新空项目、`hi`。
- 新项目、同一张官方 mascot 参考图，要求识别角色后给 15 秒 TikTok 创作策划，最多 200 字，允许只读 Skill，在媒体生成前停止。它是带图策划测试，不是重新制作成片，也不是媒体质量不回退证明。

全部操作经 Makaron Chat CLI。观察器只包装 CLI 自身现有 fetch、克隆同一个 SSE 响应读取事件、记录首个非空 stdout 写入时刻，没有修改请求或直接另调模型。时间来自单调时钟；同时记录 CLI 进程启动、实际 `/api/agent` 请求、响应头、首个非空 reasoning、首个非空 content 和 stdout。23 个有效样本的 SSE 首正文与 CLI stdout 写入差均不超过 1ms；没有把思考首包、状态、项目创建或上传完成当作首字。
