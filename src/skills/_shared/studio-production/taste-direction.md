# Taste Direction

Set a subject-specific visual point of view before composing. The goal is not a
prettier template; it is a piece whose design could not be swapped onto an
unrelated topic without feeling wrong.

## Direction Pass

1. Write a design read in one sentence: what should the viewer feel, and what
   visual cause creates that feeling?
2. Set three dials:
   - density: spare, balanced, or information-rich;
   - motion energy: restrained, rhythmic, or explosive;
   - material character: editorial, cinematic, tactile, technical, playful, or
     another topic-specific choice.
3. Name the visual grammar: typography behavior, shape language, image role,
   color contrast, camera/framing, and transition family.
4. Give every scene one dominant visual event. A scene is not a web section and
   should not default to a hero panel followed by cards.
5. Keep scene layouts distinct while sharing typography, color logic, and
   motion principles across the video.

## Atelier Decision

Use `compositionMode: "atelier"` for hero pieces, launches, trailers, and
single videos that must feel authored. Use `templated` for repeatable batches,
localization variants, and speed-sensitive internal output. State the tradeoff
in the proposal.

## Distinctness Review

Before delivery ask:

- Could this design belong to any other topic or product?
- Do several scenes reuse the same central panel with different text?
- Is motion revealing meaning, or merely decorating objects?
- Is the strongest frame recognizable with the copy temporarily hidden?

If the answer exposes sameness, revise the storyboard before polishing assets.
