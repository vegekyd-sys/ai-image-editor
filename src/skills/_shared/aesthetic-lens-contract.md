# Aesthetic Lens Contract

An aesthetic lens is a controlled variable inside an existing video workflow.
It changes how the approved subject is expressed visually; it does not replace
the workflow, story, runtime, or delivery contract.

## Fixed Surface

Keep these identical to the parent workflow and benchmark fixture:

- user prompt and reference media
- duration, aspect ratio, FPS, language, and delivery promise
- factual claims, narration, scene purposes, and ending message
- voiceover/subtitle/audio requirements
- Studio Run stages, approval policy, tool/runtime availability, preview gate,
  materialization, review, and delivery behavior
- paid-generation budget and number of planned generated asset roles

Do not introduce a shorter path, a new renderer, a subjective scoring harness,
or a compact Composition prompt. Preserve the original Remotion Composition and
Director contracts, multipart source writing, and unlimited aggregate source
size.

## Variable Surface

The lens may change only:

- the theme-to-visual thesis and governing metaphor
- composition scale, negative space, crop, depth, and focal hierarchy
- typography role and visual rhythm
- palette, material, texture, lighting, and contrast
- motion personality, paths, easing, transitions, secondary action, and timing
  emphasis inside the locked scene ranges
- prompts used to realize the same planned asset roles
- subtitle visual treatment, while retaining the same timing cues and words

## Required Decision

Before authoring assets or Composition code, derive one compact decision:

1. **Theme thesis**: why this visual mechanism is the best expression of this
   subject, not merely a fashionable style.
2. **Visual mechanism**: the recurring spatial or material transformation that
   carries setup -> transformation -> payoff.
3. **Frame grammar**: focal scale, depth, crop, negative space, and typography.
4. **Motion grammar**: tempo, path character, easing family, and secondary life.
5. **Material and light**: surfaces, texture, illumination, and contrast.
6. **Rejection list**: at least four tempting treatments that would make this
   subject generic, web-like, repetitive, or off-brand.

Write this decision into the existing proposal and storyboard fields. Do not
create a new Studio stage or spend a separate Agent attempt producing a style
document.

## Review

Use preview frames to check whether the lens is visible in the actual frame,
not merely named in prose. Reject a result when:

- a different subject could use the same frames with only text replacement
- every scene repeats the same centered card, camera scale, or transition
- the reference subject is small, hidden, or merely decorative
- polish is being simulated with darkness, glow, gradients, or tiny UI labels
- visual experimentation damages narration, subject identity, readability, or
  the final Makaron payoff

Human A/B preference is the final aesthetic judgment. The Agent should verify
execution defects, not declare its own lens the winner.
