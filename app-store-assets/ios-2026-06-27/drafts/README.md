# Draft Asset Archive

This directory contains intermediate Makaron iOS App Store screenshot iterations.

These folders are kept for traceability only. The submitted App Store assets are outside this folder:

- `../final/` for iPhone screenshots
- `../ipad-13-final/` for iPad screenshots
- `../../../../ios/App/App/Assets.xcassets/AppIcon.appiconset/` for the app icon

Draft images and prompt files are intentionally ignored by git to avoid committing large generated artifacts.
