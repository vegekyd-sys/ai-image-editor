Seedance 2.5 Flash Video Edit
Seedance 2.5 Flash Video Edit
edits an input video from a natural-language prompt. Use the source video and your prompt to guide changes to the setting, weather, style or subjects. Optional reference images and audio provide additional guidance. Choose 480p or 720p output and whether to generate audio.
Early access:
Seedance 2.5 Flash is available on WaveSpeedAI in early access. The official release is scheduled for November 15, 2026. During early access, each account can run 1 task of this model at a time; wait for it to finish before submitting the next one.
Parameters
Parameter
Required
Description
video
Yes
URL of the video to edit. Only the first 30 seconds are used; sources shorter than 4 seconds are padded to 4 seconds.
prompt
Yes
Describe the edit. Refer to reference media as
@Image 1
,
@Audio 1
in upload order.
reference_images
No
Up to 10 reference image URLs for a subject, object or style to bring into the edit.
reference_audios
No
Up to 5 reference audio URLs.
resolution
No
480p
or
720p
. Default:
720p
.
generate_audio
No
Generate synchronized audio. Default:
true
. Set to
false
to retain the source audio.
Pricing
Pricing is based on the source video duration, rounded up to the next whole second, with a minimum of 4 seconds and a maximum of 30 seconds. The rates below include both input and generation charges.
Resolution
Per second of source video
480p
$0.15
720p
$0.30
Example: a 5 second source costs $0.75 at 480p or $1.50 at 720p.
Pro Tips
Say what should change and what should stay, for example: keep the person and motion, change the street to a snowy night.
Bind reference media explicitly in the prompt, for example
@Image 1
.
Start with a short clip while testing a prompt.

API — Frequently asked questions
What is the Seedance 2.5 Flash Video Edit API?
▾
Seedance 2.5 Flash Video Edit is a ByteDance model for video editing, exposed as a REST API on WaveSpeedAI. Seedance 2.5 Flash Video Edit edits a source video using text instructions and optional image and audio references, with 480p or 720p output. Ready-to-use REST inference API, best performance, no coldstarts, affordable pricing. You can call it programmatically or try it from the playground above.
How do I call the Seedance 2.5 Flash Video Edit API?
▾
POST your input parameters to the model's REST endpoint (shown in the API tab of this playground) with your WaveSpeedAI API key in the Authorization header. Submission returns a prediction ID. Poll the result endpoint starting around every 2 seconds, increase the interval for long-running tasks, and stop on any terminal status. The playground generates Python, JavaScript, and cURL examples for submitting requests and polling results. Full request/response shape is documented at https://wavespeed.ai/docs/docs-api/bytedance/seedance-2.5-flash/video-edit.
How much does Seedance 2.5 Flash Video Edit cost per run or per second?
▾
Seedance 2.5 Flash Video Edit starts at $0.15 per run or per second. That figure is the base price — the final charge scales with the parameters you set in the form (output size, length, count, references, or whatever knobs this model exposes), so a higher-quality or larger output costs more than a minimal one. The exact cost for your current input is shown live next to the Generate button before you submit, and the actual per-call charge is recorded on the prediction afterwards.
What inputs does Seedance 2.5 Flash Video Edit accept?
▾
Key inputs: `prompt`, `video`, `resolution`, `reference_images`, `generate_audio`, `reference_audios`. The full JSON schema (types, defaults, allowed values) is rendered above the Generate button and mirrored in the API reference at https://wavespeed.ai/docs/docs-api/bytedance/seedance-2.5-flash/video-edit.
How do I get started with the Seedance 2.5 Flash Video Edit API?
▾
Sign up for a free WaveSpeedAI account to claim starter credits, copy your API key from /accesskey, then call the endpoint shown in the API tab of the playground. The playground also auto-generates a code sample in Python, JavaScript, or cURL for the parameters you've set.
Can I use Seedance 2.5 Flash Video Edit outputs commercially?
▾
Commercial usage rights depend on the model's license, set by its provider (ByteDance). Check the provider's applicable terms and WaveSpeedAI's Terms of Service before commercial use.
