# 拍立得合影

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成拍立得合影。**

上传偶像和粉丝的照片，零文字输入，自动生成拍立得风格合影。经典白框 + 手写涂鸦 + 桌面散落或麻绳悬挂，单张或多张叠放，定格最珍贵的瞬间。

使用 Nano Banana（Gemini）单次生成 + Pillow 后处理，兼顾速度和质感。

## 输出

单张或多张拍立得叠放 — 白框、手写文字、背景材质、即时成像色调。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-F 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`。

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 1:1（桌面俯拍）或 3:4（竖版手持展示）

**Prompt 模板：**

```
生成一张拍立得风格合影照片。

拍立得排列：{A}
背景材质：{D}

拍立得照片内容：
两个人物：
- Person A（偶像）: {偶像外貌描述}，面部必须严格还原参考照片
- Person B（粉丝，来自参考照片）: {粉丝外貌描述}，面部必须严格还原参考照片

互动动作：{B}
白框底部手写文字：{C}
装饰涂鸦：{F}

色调滤镜：{E}

整体风格：拍立得即时成像质感，经典白框（底部宽于顶部和两侧），
照片内容略微过曝/偏色（模拟即时成像特有的色彩表现），
背景材质清晰可见纹理，拍立得有轻微自然投影。
真实照片质感，可见皮肤纹理。

CRITICAL: 画面主体人物只能是用户照片里的人和文字中提到的人，不能凭空多出突出的人物角色（背景中符合场景的模糊路人允许存在）。拍立得照片中所有主体人物面部必须严格还原参考照片。不换脸、不混合、不修改五官。
```

### Step 4：analyze_image 人脸检查

生成后调用 `analyze_image` 检查：
- **偶像**面部与参考照片一致？
- **粉丝**面部与参考照片一致？
- 两人都在拍立得画面中？
- **没有凭空多出的主体人物？** — 主体人物只能是用户照片里的人和文字中提到的人；背景中符合场景的模糊路人允许存在
- 整体质量可接受？

不合格 → 重新生成（最多重试 1 次）。

### Step 5：输出

拍立得的色调、白框、过曝感等特征已通过 prompt 由模型直接生成，不做额外 Pillow 后处理，避免破坏即时成像的自然质感。直接使用生成结果。

### Step 6：展示结果

显示合影成品，告知用户可以：
1. 保留当前结果
2. 重新生成（换互动/换排列/换文字）
3. 换色调滤镜
4. 换背景材质
5. 多生成几张

## Rules

1. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，不像就重试
2. **不能凭空多出主体人物** — 主体人物只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的模糊路人允许存在2. **零输入** — 照片上传后立即开始，不问用户选什么风格/排列/互动，所有决策自动完成
3. **不做 Pillow 后处理** — 拍立得质感由模型直接生成，后处理会破坏即时成像的自然色彩
4. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
5. **单次生成** — 一次 generate_image 调用生成完整拍立得合影，不做多次拼接
6. **从变量池随机选** — 每次生成从 A-F 各随机选 1 个选项，确保多样性
7. **不生成违法、仇恨、色情内容** — 保持健康积极的粉丝文化
