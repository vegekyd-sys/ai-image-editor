# CCD 卡片机合影

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成CCD卡片机风格合影。**

上传偶像和粉丝的照片，零文字输入，自动生成千禧年 CCD 数码卡片机风格合影。像用 Canon IXUS / Sony Cyber-shot / Casio Exilim 在 2005 年随手拍下的那种 — 色彩浓得发腻、低像素但清晰锐利、闪光灯把人拍得白白亮亮、右下角橙色日期戳「2006.08.15」。Y2K 怀旧感，像翻到了一张千禧年的老照片。

使用 Nano Banana（Gemini）单次生成，不做后处理，保持 CCD 原生质感。

## 输出

单张合影照片 — CCD 数码卡片机风格，色彩浓郁、低像素感、日期时间戳。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-E 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`。

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 4:3（CCD 卡片机经典比例）

**Prompt 模板：**

```
生成一张2000年代CCD数码卡片机拍摄风格的合影照片。

拍摄场景：{A}
CCD相机效果：{C}
色彩风格：{D}

两个人物：
- Person A（偶像）: {偶像外貌描述}，面部必须严格还原参考照片
- Person B（粉丝，来自参考照片）: {粉丝外貌描述}，面部必须严格还原参考照片

【人脸还原 — 最高优先级】
两人的面部五官（眼型、鼻型、嘴型、脸型轮廓、眉形）必须与参考照片高度一致，像同一个人。不允许美化、不允许改变五官比例、不允许混合其他人的特征。发型发色、肤色也必须还原。如果做不到像本人，宁可牺牲场景效果也要保证人脸准确。

互动动作：{B}

日期戳和画面元素：{E}

整体风格：2000年代CCD数码卡片机（Canon IXUS / Sony Cyber-shot / Casio Exilim）拍摄感。特征包括：
- 色彩浓郁饱和，红色特别红、蓝色特别蓝（CCD感光元件的特有色彩表现）
- 低像素但锐利清晰（200-500万像素的数码感，不是胶片颗粒）
- 机载闪光灯直闪效果：人物面部白亮干净，眼睛有闪光灯白色反光点
- 自动白平衡不太准，可能整体偏暖黄或偏冷蓝
- 轻微的JPEG压缩痕迹
- 画面有种千禧年/Y2K的怀旧感，不是80年代胶片的复古，而是2005年左右的数码怀旧
- 构图随意，像朋友间随手互拍的日常照片
- 真实照片质感，可见皮肤纹理
- 画面中所有中文文字一律使用繁體中文，不使用简体

CRITICAL — 人脸还原是第一优先级: 所有主体人物的面部五官必须与参考照片高度一致，生成结果必须能一眼认出是同一个人。眼型、鼻型、嘴型、脸型轮廓、眉形、发型发色不允许偏离参考照片。不换脸、不混合其他人特征、不美化改变五官比例。画面主体人物只能是用户照片里的人和文字中提到的人，不能凭空多出突出的人物角色（背景中符合场景的模糊路人允许存在）。
```

### Step 4：analyze_image 人脸检查

生成后调用 `analyze_image` 检查：
- **偶像**面部与参考照片一致？
- **粉丝**面部与参考照片一致？
- 两人都在画面中？
- **没有凭空多出的主体人物？** — 主体人物只能是用户照片里的人和文字中提到的人；背景中符合场景的模糊路人允许存在
- 是否有CCD卡片机质感？

不合格 → 重新生成（最多重试 1 次）。

### Step 5：输出

CCD卡片机的色彩饱和、低像素感、日期戳等效果已通过 prompt 由模型直接生成，不做额外 Pillow 后处理，保持CCD原生数码质感。直接使用生成结果。

### Step 6：展示结果

显示CCD风格合影，告知用户可以：
1. 保留当前结果
2. 重新生成（换场景/换互动/换相机效果）
3. 换色彩风格
4. 换日期戳样式
5. 多生成几张

## Rules

1. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，不像就重试
2. **不能凭空多出主体人物** — 主体人物只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的模糊路人允许存在
3. **零输入** — 照片上传后立即开始，不问用户选什么场景/效果/色彩，所有决策自动完成
4. **不做 Pillow 后处理** — CCD质感由模型直接生成，后处理会破坏数码卡片机的原生色彩
5. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
6. **单次生成** — 一次 generate_image 调用生成完整合影，不做多次拼接
7. **从变量池随机选** — 每次生成从 A-E 各随机选 1 个选项，确保多样性
8. **CCD 感不是胶片感** — 色彩浓郁饱和（不是褪色）、数码噪点（不是胶片颗粒）、低像素锐利（不是柔焦）、千禧年怀旧（不是80年代复古）
9. **不生成违法、仇恨、色情内容** — 保持健康积极的粉丝文化
