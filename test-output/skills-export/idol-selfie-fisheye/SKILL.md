# 鱼眼大头自拍合影

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成鱼眼大头自拍合影。**

上传偶像和粉丝的照片，零文字输入，自动生成**俯拍视角 + 鱼眼畸变的大头搞怪自拍**。从上往下拍，两人大脸占满画面正中心、五官清晰可辨，背景被鱼眼扭曲弯曲成球面环绕在两人周围 — 像用手机 0.5x 超广角从头顶往下自拍。夜景灯光场景在鱼眼下尤其出效果。

使用 Nano Banana（Gemini）单次生成，不做后处理，保持原生质感。

## 输出

单张合影照片 — 俯拍视角 + 鱼眼畸变大头效果，两人大脸占满画面中心、五官清晰，背景球面弯曲环绕。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-E 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`：

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 1:1（鱼眼圆形画面最适合正方形）

**Prompt 模板：**

```
生成一张俯拍视角+鱼眼/超广角镜头的大头自拍合影照片。

拍摄视角：从上往下俯拍（overhead angle），相机在两人头顶上方，两人仰头看向镜头。
场景环境：{A}
鱼眼强度：{D}
光线氛围：{E}

两个人物：
- Person A（偶像）: {偶像外貌描述}，面部必须严格还原参考照片
- Person B（粉丝，来自参考照片）: {粉丝外貌描述}，面部必须严格还原参考照片

搞怪互动：{B}
夸张表情：{C}

整体风格：
- 俯拍角度（overhead/top-down selfie）：相机从头顶上方往下拍，两人仰起脸看镜头
- 大头效果：两人的大脸占满画面中心 70-80%，头部巨大突出，身体几乎看不到
- 鱼眼/0.5x超广角畸变：画面呈现明显的球面畸变，背景环境被扭曲弯曲成圆球形包裹在两人头部周围
- 五官清晰可辨：虽然有鱼眼畸变和俯拍角度，但两人的眼睛、鼻子、嘴巴等五官必须清晰可辨认
- 鼻子因广角+俯拍距离近而显得巨大，但不影响五官辨认度
- 背景在画面边缘弯曲成球面/环形，像一个小星球环绕在两人大头周围
- 搞怪自拍质感，不追求美颜而追求好玩有趣
- 真实手机0.5x超广角俯拍照片质感，像举高手机从头顶往下自拍

CRITICAL: 画面主体人物只能是用户照片里的人和文字中提到的人，不能凭空多出突出的人物角色（背景中符合场景的模糊路人允许存在）。所有主体人物面部必须严格还原参考照片。不换脸、不混合、不修改五官。鱼眼畸变只影响比例和角度，不改变五官特征。五官必须清晰可辨。
```

### Step 4：analyze_image 人脸检查

生成后调用 `analyze_image` 检查：
- **没有多余人物？** — 画面中只能出现用户照片里的人和文字中提到的人，不能有未被提及的路人或背景人影
- **偶像**面部与参考照片一致？五官清晰可辨？
- **粉丝**面部与参考照片一致？五官清晰可辨？
- 是否有俯拍角度（从上往下拍）？
- 大头效果是否明显（两人头部占画面中心大部分）？
- 鱼眼/球面畸变效果是否明显（背景弯曲环绕）？

不合格 → 重新生成（最多重试 1 次）。

### Step 5：输出

鱼眼效果由模型直接生成，不做 Pillow 后处理。搞怪风格追求原生质感，额外处理反而破坏效果。直接使用生成结果。

### Step 6：展示结果

显示鱼眼自拍合影，告知用户可以：
1. 保留当前结果
2. 重新生成（换场景/换互动/换鱼眼强度）
3. 换光线氛围
4. 多生成几张

## Rules

1. **俯拍+鱼眼+大头是三合一固定风格** — 每次生成都必须同时具备：俯拍角度（从上往下）、鱼眼球面畸变、大头占满画面中心。三者缺一不可
2. **五官必须清晰可辨** — 虽然有鱼眼畸变和俯拍角度，但两人五官（眼睛、鼻子、嘴巴）必须清晰可辨认
3. **不能凭空多出主体人物** — 主体人物只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的模糊路人允许存在
4. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，鱼眼畸变下仍需可辨认，不像就重试
4. **零输入** — 照片上传后立即开始，不问用户选什么场景/互动/鱼眼强度，所有决策自动完成
5. **不做 Pillow 后处理** — 鱼眼搞怪风格保持原生质感
6. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
7. **单次生成** — 一次 generate_image 调用生成完整合影，不做多次拼接
8. **从变量池随机选** — 每次生成从 A-E 各随机选 1 个选项，确保多样性
9. **不生成违法、仇恨、色情内容** — 保持健康积极的粉丝文化
