# 被偷拍的一天

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成八卦头条风格偷拍合影。**

上传偶像和粉丝的照片，零文字输入，自动生成港式八卦杂志封面风格合影。参考《東方新地》《東周刊》《太陽週刊》— 主偷拍照占据画面主体，巨大的多色标题文字直接叠压在照片上（关键词「同居」「偷戀」特别巨大且颜色不同），周围散落圆形嵌入小图（带彩色粗边框）和爆炸形标签，左上角有杂志 logo。信息密度高、色彩丰富、字多图多 — 港式八卦杂志的核心气质。

使用 Nano Banana（Gemini）单次生成，不做后处理。

## 输出

单张 3:4 竖版 — 港式八卦杂志封面风格，含巨大多色标题 + 嵌入小图 + 爆炸标签 + 杂志logo。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-E 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`：

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 3:4（杂志封面竖版）

**Prompt 模板：**

## Rules

1. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，不像就重试
2. **不能凭空多出主体人物** — 主体人物只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的模糊路人允许存在
3. **零输入** — 照片上传后立即开始，不问用户选什么场景/标注/标题，所有决策自动完成
4. **不做 Pillow 后处理** — 偷拍质感和八卦标注由模型直接生成，后处理会破坏原始感
5. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
6. **单次生成** — 一次 generate_image 调用生成完整画面（偷拍照 + 标注 + 标题），不做多次拼接
7. **从变量池随机选** — 每次生成从 A-E 各随机选 1 个选项，确保多样性
8. **港式八卦杂志封面是核心风格** — 必须像《東方新地》《東周刊》的封面：巨大多色标题+嵌入小图+爆炸标签+杂志logo，不是单张照片+简单标注
9. **巨大标题是最核心特征** — 标题占画面30%-50%，不同关键词不同颜色不同大小，有厚描边，直接叠压在主图上
10. **暧昧但不越界** — 两人互动暧昧有张力，但保持健康积极，不生成违法、仇恨、色情内容
