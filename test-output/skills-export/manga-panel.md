# 漫画分镜合影

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成漫画分镜合影。**

上传偶像和粉丝的照片，零文字输入，自动生成**漫画/动漫画风的多格分镜合影**。黑色粗边框分格、对话气泡、速度线、网点纸阴影、夸张的漫画表情 — 像少女漫画或少年漫画里的名场面，两人就是这部漫画的主角。

使用 Nano Banana（Gemini）单次生成，不做后处理，保持漫画质感。

## 输出

单张多格分镜图 — 3:4 竖版，2-4 格漫画分镜布局，黑色粗边框、对话气泡、漫画效果线。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-E 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`：

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 3:4（竖版漫画分镜）

**Prompt 模板：**

```
生成一张漫画/动漫风格的多格分镜合影图。

分镜叙事：{A}
分格布局：{E}

两个角色（漫画版，保留真人面部特征）：
- 角色 A（偶像）: {偶像外貌描述}，面部五官必须严格还原参考照片，用漫画画风重新诠释
- 角色 B（粉丝，来自参考照片）: {粉丝外貌描述}，面部五官必须严格还原参考照片，用漫画画风重新诠释

【人脸还原 — 最高优先级】
虽然是漫画画风，但两人的面部五官特征（眼型、鼻型、嘴型、脸型轮廓、眉形）必须与参考照片高度一致，让人一眼认出是谁。不允许改变五官比例、不允许混合其他人的特征。发型发色也必须还原。漫画风格化不等于可以改变五官——风格化只体现在线条和上色方式上，五官结构必须忠于原照。

漫画画风：{B}
漫画效果/装饰：{C}
对话气泡/文字：{D}

整体风格：
- 这是一页漫画分镜，用黑色粗边框分隔多个格子
- 每个格子是叙事的一个瞬间，构成完整的小故事
- 漫画画风统一，线条清晰，上色风格一致
- 两人的面部特征必须可辨认（虽然是漫画画风，但五官轮廓、发型发色要还原参考照片）
- 分格之间有叙事逻辑，读者能看懂剧情发展
- 气泡文字（如有）清晰可读，所有中文文字一律使用繁體中文
- 整体有漫画的视觉张力：速度线、特效、夸张表情等

CRITICAL — 人脸还原是第一优先级: 两个角色的面部五官必须与参考照片高度一致，生成结果必须能一眼认出是同一个人。眼型、鼻型、嘴型、脸型轮廓、眉形、发型发色不允许偏离参考照片。漫画风格化只体现在线条和上色方式上，五官结构必须忠于原照。画面主体人物只能是用户照片里的人和文字中提到的人，不能凭空多出突出的人物角色（背景中符合场景的模糊路人允许存在）。禁止在画面任何位置添加日期、时间戳、年份数字。
```

### Step 4：analyze_image 人脸检查

生成后调用 `analyze_image` 检查：
- **没有凭空多出的主体人物？** — 主体角色只能是用户照片里的人和文字中提到的人；背景中符合场景的路人角色允许存在
- **偶像**面部特征与参考照片一致？（漫画画风下仍可辨认）
- **粉丝**面部特征与参考照片一致？（漫画画风下仍可辨认）
- 分镜布局是否清晰？各格叙事连贯？
- 整体漫画质感可接受？

不合格 → 重新生成（最多重试 1 次）。

### Step 5：输出

漫画分镜的画风和效果由模型直接生成，不做 Pillow 后处理。漫画的线条感和色彩应保持原生质感，后处理会破坏漫画效果。直接使用生成结果。

### Step 6：展示结果

显示漫画分镜合影，告知用户可以：
1. 保留当前结果
2. 重新生成（换剧情/换画风/换效果）
3. 换分格布局
4. 换对话气泡内容
5. 多生成几张

## Rules

1. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，漫画画风下仍需可辨认，不像就重试
2. **不能凭空多出主体人物** — 主体角色只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的路人角色允许存在
3. **零输入** — 照片上传后立即开始，不问用户选什么剧情/画风/布局，所有决策自动完成
4. **不做 Pillow 后处理** — 漫画质感由模型直接生成，后处理破坏线条感和漫画效果
5. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
6. **单次生成** — 一次 generate_image 调用生成完整分镜图，不逐格生成
7. **从变量池随机选** — 每次生成从 A-E 各随机选 1 个选项，确保多样性
8. **分镜叙事完整** — 多格之间必须有剧情逻辑，不是随机拼凑的独立画面
9. **不生成违法、仇恨、色情内容** — 保持健康积极的粉丝文化
