# 闪光灯抓拍合影

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成闪光灯抓拍合影。**

上传偶像和粉丝的照片，零文字输入，自动生成闪光灯抓拍风格合影。暗房派对/KTV走廊/深夜街头……闪光灯在黑暗中定格两人的瞬间表情，运动模糊+高光过曝+偶然抓拍感。

使用 Nano Banana（Gemini）单次生成 + Pillow 后处理，兼顾速度和质感。

## 输出

单张合影照片 — 暗环境闪光灯直闪效果，人物高光过曝，背景昏暗，抓拍偶然感。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-E 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`：

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 3:4（竖版抓拍）

**Prompt 模板：**

```
生成一张闪光灯抓拍风格合影照片。

拍摄场景：{A}
镜头角度：{E}

两个人物：
- Person A（偶像）: {偶像外貌描述}，面部必须严格还原参考照片
- Person B（粉丝，来自参考照片）: {粉丝外貌描述}，面部必须严格还原参考照片

互动动作：{B}
被拍到时的表情反应：{C}
闪光效果：{D}

整体风格：暗环境闪光灯抓拍，一次性相机/傻瓜相机质感，
闪光灯直闪导致人物面部高光过曝，背景昏暗，强烈明暗对比，
画面有运动模糊和偶然感，重颗粒噪点。
真实照片质感，不是棚拍，是偶然被拍到的真实瞬间。

CRITICAL: 画面主体人物只能是用户照片里的人和文字中提到的人，不能凭空多出突出的人物角色（背景中符合场景的模糊路人允许存在）。所有主体人物面部必须严格还原参考照片。不换脸、不混合、不修改五官。
```

### Step 4：analyze_image 人脸检查

生成后调用 `analyze_image` 检查：
- **偶像**面部与参考照片一致？
- **粉丝**面部与参考照片一致？
- 两人都在画面中？
- **没有凭空多出的主体人物？** — 主体人物只能是用户照片里的人和文字中提到的人；背景中符合场景的模糊路人允许存在
- 整体质量可接受？

不合格 → 重新生成（最多重试 1 次）。

### Step 5：输出

闪光灯抓拍的颗粒感、高对比、暗背景等效果已通过 prompt 由模型直接生成，不做额外 Pillow 后处理，避免画面过暗或颗粒过重。直接使用生成结果。

### Step 6：展示结果

显示合影成品，告知用户可以：
1. 保留当前结果
2. 重新生成（换互动/换表情/换场景）
3. 换闪光效果
4. 多生成几张

## Rules

1. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，不像就重试
2. **不能凭空多出主体人物** — 主体人物只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的模糊路人允许存在2. **零输入** — 照片上传后立即开始，不问用户选什么风格/互动/场景，所有决策自动完成
3. **不做 Pillow 后处理** — 闪光灯质感由模型直接生成，后处理会过度加重颗粒和暗度
4. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
5. **单次生成** — 一次 generate_image 调用生成完整合影，不做多次拼接
6. **从变量池随机选** — 每次生成从 A-E 各随机选 1 个选项，确保多样性
7. **不生成违法、仇恨、色情内容** — 保持健康积极的粉丝文化
