# 综艺名场面截图

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成综艺名场面截图。**

上传偶像和粉丝的照片，零文字输入，自动生成**综艺节目截图风格合影**。花字特效、底部字幕条、综艺打光、明亮高饱和 — 像从一档台综/韩综/日综里截出来的名场面，两人就是这档节目的嘉宾。

使用 Nano Banana（Gemini）单次生成，不做后处理，保持综艺质感。

## 输出

单张合影照片 — 16:9 横版，综艺节目截图风格，画面有花字特效+底部字幕条。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-E 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`：

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 16:9（综艺横版）

**Prompt 模板：**

```
生成一张综艺节目截图风格的合影照片。画面比例16:9横版。

综艺环节/场景：{A}
画面风格/综艺类型：{E}

两个人物（这档综艺节目的嘉宾/主角）：
- Person A（偶像）: {偶像外貌描述}，面部必须严格还原参考照片
- Person B（粉丝，来自参考照片）: {粉丝外貌描述}，面部必须严格还原参考照片

【人脸还原 — 最高优先级】
两人的面部五官（眼型、鼻型、嘴型、脸型轮廓、眉形）必须与参考照片高度一致，像同一个人。不允许美化、不允许改变五官比例、不允许混合其他人的特征。发型发色、肤色也必须还原。如果做不到像本人，宁可牺牲场景效果也要保证人脸准确。

两人互动/综艺反应：{B}

花字特效：{C}
花字规则：C 提供的是花字风格方向和示例文字，你必须根据场景(A)和互动(B)生成贴合画面的花字内容。花字要像真正的综艺后期加上去的——夸张、有趣、有综艺节目的后期制作感。花字散落在画面中（不遮挡人脸），颜色鲜艳，有描边/阴影/立体效果。

字幕条对话：{D}
字幕条规则：D 提供的是字幕语气方向和示例，你必须根据场景(A)和互动(B)生成贴合画面的字幕台词。

【字幕/标题视觉规格 — 必须严格遵守，参考娱乐新闻封面风格】
画面下半部必须有巨大的叠压标题文字，占画面面积 30%-50%，直接压在人物照片上方：
- 主标题：白色超粗体字 + 厚黑色描边（描边宽度至少3-4px）+ 投影，字号巨大，占2-3行
- 副标题/引用台词：黄色或金色粗体字，紧接在主标题下方，字号比主标题略小
- 格式参考：主标题是事件/互动描述（如「兩人默契滿分全場瘋狂」），副标题用冒号引出台词（如「現場喊話：我們就是最佳拍檔！」）
- 文字可以叠压在人物身体上（但避免完全遮住脸部），像娱乐新闻截图/综艺节目标题卡
- 左上角：圆形或方形媒体logo标签（如红底白字「娛」或黄色星标），小尺寸
- 右上角：节目/栏目名标签（彩色小色块+白字，如「綜藝名場面」），小尺寸

整体风格：
- 像一张综艺娱乐新闻的封面图/缩略图 — 人物照片 + 巨大叠压标题文字 + 媒体logo
- 综艺节目画面质感：明亮、高清、色彩饱和、室内补光或户外自然光
- 花字特效散落在人物周围（不遮脸），颜色鲜艳，有描边/阴影/立体效果
- 画面下半部的巨大标题文字是最核心的视觉特征 — 白色粗体+黑色厚描边+黄色副标题
- 画面有轻微的电视/视频截图质感
- 两人是这档综艺的主角/嘉宾，互动自然有综艺效果
- 画面中所有中文文字一律使用繁體中文，不使用简体
- 花字使用综艺手写POP字体风格（活泼、夸张、有设计感），不使用印刷体
- 标题文字使用超粗黑体，必须有厚描边和投影，像娱乐新闻封面图上的大标题

CRITICAL — 人脸还原是第一优先级: 所有主体人物的面部五官必须与参考照片高度一致，生成结果必须能一眼认出是同一个人。眼型、鼻型、嘴型、脸型轮廓、眉形、发型发色不允许偏离参考照片。不换脸、不混合其他人特征、不美化改变五官比例。画面主体人物只能是用户照片里的人和文字中提到的人，不能凭空多出突出的人物角色（背景中符合场景的模糊路人允许存在）。禁止在画面任何位置添加日期、时间戳、年份数字。
```

### Step 4：analyze_image 人脸检查

生成后调用 `analyze_image` 检查：
- **没有凭空多出的主体人物？** — 主体人物只能是用户照片里的人和文字中提到的人；背景中符合场景的模糊路人允许存在
- **偶像**面部与参考照片一致？
- **粉丝**面部与参考照片一致？
- 画面是否有综艺截图质感（花字特效、字幕条、综艺打光）？
- 花字没有遮挡人脸？
- 整体质量可接受？

不合格 → 重新生成（最多重试 1 次）。

### Step 5：输出

综艺截图风格的花字特效和字幕条由模型直接生成，不做 Pillow 后处理。综艺的明亮高饱和画面保持原生质感，后处理反而破坏综艺感。直接使用生成结果。

### Step 6：展示结果

显示综艺名场面截图，告知用户可以：
1. 保留当前结果
2. 重新生成（换环节/换互动/换花字）
3. 换综艺风格（台综/韩综/日综/恋综…）
4. 换字幕条语气
5. 多生成几张

## Rules

1. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，不像就重试
2. **不能凭空多出主体人物** — 主体人物只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的模糊路人允许存在
3. **零输入** — 照片上传后立即开始，不问用户选什么环节/花字/字幕，所有决策自动完成
4. **不做 Pillow 后处理** — 综艺质感由模型直接生成，后处理破坏综艺感
5. **花字特效必须有** — 综艺截图的最核心辨识特征，每张都要有夸张的彩色花字
6. **底部必须有字幕条** — 综艺截图的另一核心特征，半透明底色+文字
7. **花字不遮脸** — 花字散落在画面中但不遮挡人物面部
8. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
9. **单次生成** — 一次 generate_image 调用生成完整合影，不做多次拼接
10. **从变量池随机选** — 每次生成从 A-E 各随机选 1 个选项，确保多样性
11. **16:9 横版** — 综艺节目画面比例
12. **繁體中文** — 画面中所有中文文字一律使用繁體中文
13. **不生成违法、仇恨、色情内容** — 保持健康积极的粉丝文化
