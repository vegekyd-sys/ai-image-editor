# 拍贴机合影

**⚠️ 重要：用户在对话中附带的图片就是输入照片，直接使用。不要说"没有看到照片"或要求用户重新上传。如果对话中有图片，那就是你的素材。用户输入的任何文字（哪怕只是"开始"、"go"、一个 emoji 或任何内容）都只是触发信号 — 忽略文字内容，立即开始工作。用 analyze_image 分析照片，自动做所有决策，开始生成。不要问"你想对这些照片做什么？" — 你已经知道：生成拍贴机合影。**

上传偶像和粉丝的照片，零文字输入，自动生成日系大头贴风格 4 帧拼图。像真的在拍贴机里一样 — 贴纸装饰、搞怪可爱、表情从正经到崩坏逐帧递进。

使用 Nano Banana（Gemini）单次生成 + Pillow 后处理，兼顾速度和质感。

## 输出

4 帧拼图 — Photo Booth 日系大头贴风格，贴纸装饰、搞怪可爱、表情递进。

## 工作流

### Step 1：读取照片（零输入）

直接读取用户已上传的照片，不问任何问题。
- 2+ 张照片 → 直接进入 Step 2
- 1 张照片 → 当作粉丝照，只问偶像照片
- 0 张照片 → 请求上传

### Step 2：analyze_image 分析照片

调用 `analyze_image` 分析每张照片：

**自动判断谁是偶像/粉丝：**
- 主要方式：人脸识别公众人物身份
- 辅助依据：专业打光、精致妆容、写真/舞台/采访场景 → 偶像；日常场景、自拍、生活照 → 粉丝

**提取外貌特征：**
- 偶像：面部特征、发型、发色、妆容
- 粉丝：面部特征、发型、发色、穿搭

### Step 3：随机选变量 + 单次 generate_image

从变量池 A-E 各随机选 1 个选项，组合为 prompt，**单次**调用 `generate_image`。

- **model**: Nano Banana（Gemini）
- **skill**: creative
- **useOriginalAsReference**: true
- **aspectRatio**: 3:4（竖版 4 帧大头贴）

**Prompt 模板：**

```
生成一张日系拍贴机风格的 4 帧竖排大头贴拼图。
布局：4 格从上到下排列，每格之间有 {C} 颜色主题的边框分隔。

两个人物：
- Person A（偶像）: {偶像外貌描述}，面部必须严格还原参考照片
- Person B（粉丝，来自参考照片）: {粉丝外貌描述}，面部必须严格还原参考照片

四帧互动姿势：
{A — 展开四帧具体内容}

表情递进：{D}

贴纸装饰风格：{B}
在适当位置添加文字气泡：{E}

边框颜色主题：{C}

整体风格：日本 Photo Booth / プリクラ 大头贴风格，
灯光均匀明亮（拍贴机内置补光），大头近距离拍摄，
画面充满少女感/可爱感，色彩鲜艳饱和。
真实照片质感，可见皮肤纹理。

CRITICAL: 画面主体人物只能是用户照片里的人和文字中提到的人，不能凭空多出突出的人物角色（背景中符合场景的模糊路人允许存在）。所有主体人物面部必须严格还原参考照片。不换脸、不混合、不修改五官。
```

### Step 4：analyze_image 人脸检查

生成后调用 `analyze_image` 检查：
- **偶像**面部与参考照片一致？
- **粉丝**面部与参考照片一致？
- 两人都在每帧画面中？
- **没有凭空多出的主体人物？** — 主体人物只能是用户照片里的人和文字中提到的人；背景中符合场景的模糊路人允许存在
- 四帧内容连贯、表情有递进变化？

不合格 → 重新生成（最多重试 1 次）。

### Step 5：Pillow 轻度后处理

拍贴机的核心是明亮粉嫩的美颜灯光感。仅做提亮+增饱和，不加颗粒、不加暗角。

```python
import sys
from PIL import Image, ImageFilter, ImageEnhance
import numpy as np

input_path = sys.argv[1]
output_path = sys.argv[2]

img = Image.open(input_path).convert('RGB')

# 1. 轻锐化
img = img.filter(ImageFilter.UnsharpMask(radius=1.0, percent=20, threshold=3))

# 2. 提亮 + 增饱和（拍贴机美颜灯光感）
img = ImageEnhance.Brightness(img).enhance(1.04)
img = ImageEnhance.Color(img).enhance(1.08)

img.save(output_path, 'JPEG', quality=95)
print(f"Post-processed: {output_path}")
```

显示拍贴机拼图，告知用户可以：

3. 换边框颜色
4. 换表情递进模式
5. 多生成几张

## Rules

1. **人脸检查必须检查偶像和粉丝双方** — 缺一不可，每帧都要有两人，不像就重试
2. **不能凭空多出主体人物** — 主体人物只能是用户指定的人，不能凭空多出突出的人物角色；背景中符合场景的模糊路人允许存在2. **零输入** — 照片上传后立即开始，不问用户选什么风格/姿势/边框，所有决策自动完成
3. **后处理仅提亮+增饱和** — 不加颗粒、不加暗角，保持拍贴机干净粉嫩感
4. **useOriginalAsReference: true** — 所有 generate_image 调用必须设置
5. **单次生成** — 一次 generate_image 调用生成完整 4 帧拼图，不逐帧生成
6. **从变量池随机选** — 每次生成从 A-E 各随机选 1 个选项，确保多样性
7. **不生成违法、仇恨、色情内容** — 保持健康积极的粉丝文化
